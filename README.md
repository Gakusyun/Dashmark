# DashMark

**Links, organized. Instantly.**

**链接有序，即刻可达。**

DashMark 是一个专注分组书签的极简起始页。它安静、迅速、不打扰，只在你需要时，把你带到正确的地方。

## ✨ 特性

- ⌨️ **统一命令栏**
  一个输入框同时完成两件事：实时检索本地收藏（↑↓ 选择、Enter 打开），
  无匹配时按 Enter 直接用默认引擎搜索网络。
  `Ctrl / ⌘ + K` 或 `/` 随时唤出。
- 📁 **分组管理**
  单层分组，顶部标签栏一键切换；一个链接可同时属于多个分组。
- 🔖 **链接与文字记录**
  链接卡片自动抓取网站图标、只显示域名；文字记录可随时阅读与就地编辑。
- 🌗 **深色 / 浅色主题**
  支持跟随系统，或手动切换。
- 💾 **本地优先 + 备份**
  数据存放于浏览器 IndexedDB，不经过服务器；支持 `.json` 与 `.json.gz` 导入导出。
- 📱 **PWA**
  可安装到桌面 / 主屏，离线可用。

## 🚀 开发

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # 类型检查 + 生产构建
pnpm lint
pnpm preview
```

## ⌨️ 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl / ⌘ + K` | 聚焦命令栏 |
| `/` | 聚焦命令栏（未在输入时） |
| `↑` / `↓` | 在搜索结果间移动 |
| `Enter` | 打开选中项 |
| `Ctrl / ⌘ + Enter` | 用搜索引擎搜索当前关键词 |
| `Esc` | 清空搜索 / 关闭浮层 |

## 🧱 技术栈

React 19 · TypeScript · Tailwind CSS v4 · Vite · Dexie (IndexedDB) · vite-plugin-pwa

## 📦 数据说明

- 所有数据存储在浏览器 `IndexedDB`（数据库名 `DashmarkDB`），不会上传。
- 清理浏览器数据会导致丢失，建议定期用「设置 → 数据 → 导出备份」保存。
- 从旧版本（v1/v2）升级时会自动迁移本地数据。
